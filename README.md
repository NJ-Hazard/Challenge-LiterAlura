## 📚 Descripción
Challenge-LiterAlura es un proyecto desarrollado como parte del programa de Alura Latam. Proporciona funcionalidades para gestionar y consultar información sobre libros y autores.

## 🚀 Guía de Uso

### Requisitos Previos
- **Java 11+** instalado
- **Maven 3.6+** configurado
- **Base de datos** (PostgreSQL/MySQL) - verificar configuración en `application.properties`

### Instalación y Ejecución

#### 1. Compilar el proyecto
```sh
./mvnw clean compile

1. Ejecutar la aplicación
java -jar target/literalura-0.0.1-SNAPSHOT.jar
